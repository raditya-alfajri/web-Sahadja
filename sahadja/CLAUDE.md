# Proyek: Landing page Kedai Kopi Sahadja

Landing page statis untuk warkop pinggir jalan di Tegal. Tugas kuliah, deadline besok.

## Aturan
- Hanya HTML, CSS, dan JavaScript murni. Tanpa framework, tanpa library tambahan.
- Struktur file: index.html, css/style.css, js/script.js, assets/img/.
- Folder `referensi/` berisi versi lengkap yang sudah jadi. Jadikan acuan desain dan fitur,
  tapi tulis kodenya di file proyek utama, jangan menyalin seluruh file sekaligus.
- Tahap 1–6 (kerangka, CSS dasar, navbar, hero, layanan, cerita, best seller) sudah selesai.
  Jangan ubah bagian itu kecuali untuk memperbaiki error.
- Nama class, id, variabel, dan komentar kode memakai Bahasa Indonesia,
  sama seperti kode yang sudah ada.
- Tidak ada fitur order online. Semua tombol pesan mengarah ke WhatsApp lewat class `link-wa`.
- Setelah setiap perubahan, jelaskan singkat apa yang diubah dan kenapa,
  supaya saya bisa memahami dan mempresentasikannya.
